How it works

The page loads Whisper, an open speech recognition model from OpenAI, into your browser. On computers and phones that support WebGPU it uses the graphics chip; otherwise it falls back to the processor, which is slower. Nothing is sent to FAIND for processing.

The first run downloads the model, which your browser then keeps. The download comes from Hugging Face and the code from jsDelivr, two public hosting services; they see a normal file request, never your recording. See the privacy notes.

What to expect

OutputPlain text with punctuation, plus SRT and VTT subtitles with timestamps.
SpeakersNot separated. You get one continuous transcript.
SpeedDepends on your device. A recent laptop with WebGPU is quick; an older phone can be several times slower than the recording.
Limits60 minutes and 400 MB per file. Keep the tab open while it works.
AccuracyBest on clear speech in widely spoken languages. Noise, accents and overlapping voices reduce it.

Questions

Is my audio uploaded anywhere?

No. The model is downloaded to your browser and the transcription runs on your device. The file is never sent to FAIND or to any other server.

Is it really free?

Yes: no account, no watermark, no minutes limit. Your own device does the work, so it costs FAIND nothing to run.

Which languages does it support?

Whisper handles about a hundred languages. Pick one from the list or leave it on automatic detection. Setting the language yourself usually helps with short or noisy clips.

Does it tell speakers apart?

No. The output is one continuous transcript with timestamps, without speaker labels.

Why is the first run slow?

The first time, your browser downloads the speech model. It is then stored by the browser, so later runs start straight away.

How long can the file be?

Up to 60 minutes and 400 MB per file. For longer recordings, split the file first.
